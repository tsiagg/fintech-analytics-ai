# Phase 4 — Streamlit AI analytics (dashboard + BI + CFO)

**Parent brief:** See `../Analytics Project Summary - Fintech Simulation.docx`.

**Prerequisites:** Phase 2b (marts + MetricFlow metrics); Phase 3 DAG keeping data fresh (dashboard can be built in parallel on manual loads before Phase 3 ships).

**Status (2026-06-19):** **~90% complete** — Executive Dashboard v1, Data Spot Check, **BI Assistant**, and **AI CFO** shipped. AI CFO is a `reporting/` backend package run by the Airflow `generate_cfo_report` task: numbers (rolling WoW, MTD same-period, pace-adjusted target attainment for the three seed targets, z-score anomalies, numpy.polyfit + run-rate forecasts) computed in Python, the CFO model writes the narrative, a Jinja2 template renders a McKinsey-style HTML report stored in `analytics_dev.cfo_report_runs`, and `app/pages/3_AI_CFO.py` embeds the latest. Pending: rebuild dbt for the new `new_users` column (Option A).

## Goal

Deliver a **local AI-powered fintech analytics app** with three Streamlit pages: executive dashboard (metrics only), **BI Assistant** (reactive), and **AI CFO** (proactive executive report). Metrics come from the warehouse and semantic layer; LLMs **interpret** only.

**Out of scope:** FastAPI layer, local Ollama, Streamlit pipeline/DAG monitoring page, autonomous agent loops.

### Two separate AI modes (do not merge)

| Mode | Behavior |
|------|----------|
| **BI Assistant** | User-driven; allowlisted metrics; optional SQL + chart; concise factual answers |
| **AI CFO** | Scheduled or on-demand report; inputs = precomputed JSON (snapshots, deltas, targets, anomalies, forecasts); fixed section template |

**Guardrails:** No hallucinated numbers; retrieve metrics before LLM; cap prompt size; log token usage.

### Data access rules

- Query **`analytics_dev` marts** and MetricFlow-compiled metric SQL only.
- Do **not** query raw `public` tables from the app.
- Do **not** duplicate KPI formulas in Python beyond period filters and deltas.

### LLM provider (~€20/month budget)

- **OpenRouter** (recommended): prepaid credits, OpenAI-compatible API, swap models without code changes.
- **Models:** cost-efficient tier for BI (e.g. Gemini Flash, GPT-4o-mini, DeepSeek); same or slightly stronger for CFO daily report.
- **Env:** `LLM_API_BASE`, `LLM_API_KEY`, `LLM_MODEL_BI`, `LLM_MODEL_CFO`; document in `.env.example` (Phase 5).
- **Cost control:** small context (KPI JSON not full tables), `max_tokens`, OpenRouter spend limit ~€20.

### BI Assistant (reactive)

- Left: chat + suggested prompts.
- Right: chart, SQL used, metrics table, explanation.
- RAG: semantic metric YAML + `marts.yml` chunks.
- Workflow: intent → metric retrieval / allowed SQL → numbers → LLM explains.

### AI CFO (proactive)

**Inputs (computed in Python):** KPI snapshots, deltas, target comparisons, anomaly flags, forecast series, regional summaries.

**Output sections (template):**

1. Executive Summary  
2. Monthly Trends vs Targets  
3. Revenue Analysis  
4. User Activity Analysis  
5. Cash Flow Analysis  
6. Regional Performance  
7. Risks & Anomalies  
8. Forecast Outlook  
9. Recommended Actions  

**Forecasting:** moving averages / simple trend on `mrt_company_daily_kpi`; LLM interprets, does not invent forecast values.

**Trigger:** optional final task in Phase 3 DAG, or “Generate report” button in app.

### Dashboard v1 scope

**Serving marts consumed:**

| Mart | Grain | Used for |
|------|-------|----------|
| `mrt_company_daily_kpi` | Company × day | KPI cards, sparklines, per-user charts |
| `mrt_geo_daily_revenue` | Country × day (+ `region`) | Weekly stacked bar; Streamlit aggregates to region or country |

**KPI cards (from `mrt_company_daily_kpi`):** net revenue, active users, net flow, withdrawal ratio — each with Plotly sparkline + period comparison badge (MTD or WoW).

**Charts shipped:**

- Weekly stacked bar — gross revenue by region or country (toggle); tooltip shows **% share of week**
- Net revenue per active user (line + min/max markers)
- Gross deposit per active user (line + min/max markers)

**Deferred v2:** top instrument groups, affiliate summary, CFO summary snippet on dashboard (add when those marts / pages exist).
