# About

This project demonstrates how I approach an analytics engineering role: understand the business model, turn it into reliable data products, and communicate the result in a form that supports decisions.

The modelling layer is mine. The Streamlit surfaces and larger Python modules were built with an AI coding agent under direction and review.
