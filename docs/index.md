# Fintech Analytics AI

An analytics engineering portfolio built around one idea: **metrics are computed and tested in the warehouse, and AI is only allowed to interpret them.**

The project is a complete stack for a fictional retail trading broker. A simulator writes trades, deposits, withdrawals and signups into Postgres. dbt turns those into tested marts and a semantic layer of 57 governed metrics. Airflow runs it daily. Streamlit exposes it as a dashboard, a chat BI assistant, and an automatically generated CFO report.

## The problem it answers

Most "AI on top of your data" demos let a language model write SQL against raw tables. That produces confident, plausible, wrong answers, and there is no way for a stakeholder to tell the difference. It also means the definition of a metric like net revenue lives inside a prompt, where nobody can test it.

This project takes the opposite approach. Net revenue is defined once, in dbt and MetricFlow, with tests around it. The AI layer can request that metric by name and nothing else. When the LLM produces a sentence, every number in it came out of the warehouse.

## What is real and what is simulated

The warehouse, the models, the metrics, the tests, the orchestration and the AI guardrails are all real and running. The **source data is synthetic**, produced by a scenario-driven simulator in [`simulation/`](https://github.com/tsiagg/fintech-analytics-ai/tree/main/simulation). That is deliberate: as an analytics engineer I would not be generating or ingesting source data, so the simulator stands in for the data engineering team and the upstream product. It is described briefly in [Architecture and data model](02-architecture-and-data-model.md#where-the-data-comes-from) and not dwelt on further.

## A sample artifact

The CFO report is generated by an Airflow task, not written by hand. You can [open a real generated report](cfo_report_latest.html) to see the output: nine sections, each with the numbers computed in Python and the prose written by an LLM that only ever saw those numbers.
